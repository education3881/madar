# Ruling #131 — Two instruments that decline different populations are each other's evidence, and the one that can see a class is the evidence about that class

**Filed 2026-11-06 at the point of filing, from the standing queue's own head: item 34 at 15 days**,
beside #130, which is the negative half of the same measurement. Family: **assertion discipline**
— *how a check earns trust* — which keeps a running member count, so **five homes move** and the
family goes to **FIFTY**. Its fiftieth member, and the **fourth** about a decline.

## The rule

**When an instrument declines a class, ask what else in the toolkit reads that class differently
before concluding the class is unobserved.** Two instruments that fetch the same URL for different
purposes will usually decline *different* populations, because the thing each one needs from the
document is different. Where they differ, **the instrument that can see a class is the evidence about
that class** — and the union of two partial instruments is routinely better covered than either one's
own output suggests.

This is the method a run owes before it writes *unobservable* in a header or opens a queue row for an
unreachable population.

## What earned it

`qa_citation_identity` (#112) cannot evaluate a single PDF. Nineteen of its 232 registers are PDFs
and **0 are comparable** — it must read the document's own text to find a quoted string, and this
runner has no PDF text client. Item 34's whole premise was that those PDFs are therefore dark.

**They are not dark, and the instrument that lights them was already running in the same
`postbuild`.** `qa_claim_registers` (#111) asks an **archive** whether a snapshot of the URL exists.
It never reads the document at all, so a PDF costs it nothing — and it answers for **18 of the 19**,
reporting them as the best-archived class in the corpus (94.7%).

So the honest statement about PDFs is not *unobserved*. It is: **their persistence is measured and
good; their quotation identity is unmeasured.** That is a precise, useful sentence, and no run could
write it from either instrument's own output, because each instrument reports a coverage figure over
its own population and neither knows the other exists.

  cover; here, the sibling covers and was never named.

## The cheap test, so it is executable rather than admirable

For any class an instrument declines, ask the two questions that separate the cases:

1. **What does my instrument need from the document that it cannot get?** (`qa_citation_identity`
   needs the text layer.)
2. **Does any other instrument in the toolkit answer a question about this URL without needing that
   thing?** (`qa_claim_registers` needs only the URL string and an archive.)

If the answer to (2) is yes, **the decline's header carries that instrument's finding for the
declined class**, as a figure and a date. If the answer is no, the decline says *no instrument of
ours reads this class*, which is a stronger and rarer claim than *this instrument does not*.

## What it does not license

It does not say the union is adequate. Persistence and identity are different claims, and a PDF that
an archive holds a copy of can still be misquoted in our own body with nothing able to notice —
**which is exactly what item 82 asks about and what no instrument on either side can answer today.**
The union is better *coverage*, not better *evidence about the same question*. Reading one
instrument's green as another's would be the 2026-08-09 vacuous-pass defect wearing a second
instrument's clothes.

## The general form

*A toolkit's coverage is not the maximum of its instruments' coverages and it is not their minimum;
it is their union, and nobody computes it.* Each instrument reports a fraction over its own
population, and the operation reads those fractions as if they were about the corpus. Before writing
down that a class is unobserved, cross the registers — the answer may already be on disk, written by
a check that was never asked.
