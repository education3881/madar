## Transliteration — the Dutch name-routing convention (extends #28b)

Dutch orthography is phonemic and regular, so a Dutch byline routes **by Dutch phonology**, CONFIRMED-by-convention (not PROVISIONAL — contrast Australia's Gniel, whose pronunciation is genuinely unrecoverable from spelling):

- **Alida Oppers → أليدا أوبِرس** — `Alida` /aːˈliːdaː/ (long *i* = ي); `Oppers` /ˈɔpərs/ (short *o* = و vowel-value أ‑و; double *pp* collapses to one ب; schwa carried as kasra).
- **Annet Dries → آنِت دريس** — `Annet` /ˈɑnɛt/; `Dries` — the Dutch digraph **`ie` = long /i/ → ي** (دريس, not درايس). This is the one Dutch spelling rule worth naming, because `ie` is a false friend for an Arabic composer reading it as a diphthong.

**Routing values banked for future Dutch bylines:** `ie` → ي (long i); `oe` → و (long u); `ij`/`ei` → diphthong (اي); `ui` → approximate أوي; `g`/`ch` → guttural, render خ or غ by context; single vs double consonant is a vowel-length cue in Dutch, not a consonant to double in Arabic. PROVISIONAL stays reserved for a name that clears none of these — the pre-ship audio check earns its place only there.
