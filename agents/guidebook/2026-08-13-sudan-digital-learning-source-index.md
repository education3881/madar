## Method note — a lineage claim is a figure (the provenance axes)
The Ed05 Sudan recon surfaced a defect class the figure axes (#12–#28) don't yet name: **program lineage asserted from resemblance.** The tempting spine — "Sudan's wartime digital learning spaces run the platform Sudan invented" — is supported by *place* (Kassala), *technology* (tablets, solar), and *idea* (facilitator-led game learning), but **no served-text source states the identity**, and one register (War Child AR2025's CWTL country list) points the other way. Same place + same tech + same look ≠ same instrument.

**The rule:** a claim that instrument B *is* / *descends from* / *continues* instrument A is a citable figure carrying its own axes — **same programme / formal successor / rebrand / independent parallel** — and must be traced verbatim to a source that states the relationship, exactly as a number is traced to a source that states the value. Absent that trace, the honest draft carries the two instruments side by side, joined by idea and geography, with the connection unasserted. Resemblance is a lead (#26 family: an observation that a link may exist), never the citation.

**Where it generalises on the slate:** Egypt (is the 2025 hiring drive "the same programme" as the 2019 one, or a successor with a new name?), Rwanda (CBC's descent from the 2016 reform), any "Phase II" claim, any NGO programme that changes funder mid-life. The scoped-instrument family (rows 15/19/20/21) scopes a *number*; this note scopes an *identity*.
