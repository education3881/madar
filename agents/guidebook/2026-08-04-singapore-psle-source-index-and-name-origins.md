## 2. Composition — the three name-origins of a Singapore byline (extends #28b)

A Singapore piece routinely carries names from **three scripts-of-origin at once**, and each has its own confidence path to a shipped Arabic form. #28b (a name you can spell but cannot *hear* stays PROVISIONAL) is the fallback; for Singapore, all three origins usually have a **convention-backed** form that clears the bar before fallback — as all three named humans did today:

1. **Malay / Muslim names → restore to the Arabic root, don't phonetically transliterate the English spelling.** `Mohamed Ashiq → محمد عاشق` — CONFIRMED. "Ashiq" is عاشق; rendering it phonetically (e.g. أشيق) would erase an Arabic-origin word the reader already holds. This is the strongest confidence path — the name *is* Arabic, romanized into English and now restored.
2. **Chinese romanizations → follow Arabic-media convention for attested public figures.** `Chan Chun Sing → تشان تشون سينغ` — CONFIRMED-by-convention (a sitting minister; the standard Arabic-media rendering of the romanization). `Chua → تشوا` (surname 蔡, standard). When the figure is **not** media-attested and the dialect romanization is ambiguous, this path drops to #28b PROVISIONAL.
3. **English given names → phonetic transliteration.** `Grace → غريس` — CONFIRMED (common name, unambiguous sound).

**The rule:** identify the name's origin first, then pick the path — restore (Malay/Muslim), convention (attested Chinese romanization), or phonetic (English/other). PROVISIONAL (#28b) is only for a name that clears **none** of the three (contrast Australia's *Gniel* — an English/Germanic surname whose sound the served-text primaries never voiced). Institutions keep their Latin tag per #28a: PSLE / FSBB / MOE / SEAB / AL / COP each glossed once + carried in Latin (bilingual-search asset).
