Prevention rule codified into the RUNBOOK — 1 of 2

The QA perimeter includes the artefacts the operation renders for humans, not only the ones it publishes for readers. Every HTML artefact rendered for a person — daily brief, weekly review, memo, packet — is opened and looked at before the push, and carries the same container assertion the site pages get. A template change is a change to every artefact that template will ever produce: when a shared template is edited, the run re-renders one artefact from it and inspects the output, exactly as ruling #16 requires for the site. If you open it, we check it.
