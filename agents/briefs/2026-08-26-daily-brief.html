Research — ruling 36, and the part I think is actually the finding
The obvious fix is to draw the missing card. I did that. But it fixes today and not the class, because nothing stops the next page from being added without one.

Ruling 36: a promise must be derived from the thing it promises, never declared beside it. When markup makes a claim about an asset, the claim has to be computed from the asset, in the same expression, so the two cannot be separately true. twitter:card is now ogImageAbs ? 'summary_large_image' : 'summary'. A page without a card can no longer promise one, whatever anybody writes in a template later — including me.

The corollary is the part worth keeping: there are always two fixes for a broken promise — supply the missing thing, or make the promise underivable without it. Only the second fixes the class. Take it in the same commit as the first.
Why it survived 93 days: twitter:card reads as configuration — a setting for how the site presents itself. It is in fact a per-page factual claim, and every per-page factual claim needs that page's own data behind it. The rule generalises past Open Graph: hreflang pairs, feed enclosures, lastmod, JSON-LD citations are all claims about assets.

Research — the routing rule the Africa edition is going to need
Guidebook row 30. In Bantu orthography, ph is an aspirated /p/, never /f/. The h marks aspiration, exactly as in th and kh in the same writing systems. So Phiri — the most common surname in Zambia and Malawi — is pee-ree, and goes to بيري, not فيري.

This matters beyond one name. Latin script is a false friend here in a specific, predictable way: the same two letters mean /f/ in Greek-derived English vocabulary and /pʰ/ in Bantu orthography, and an Arabic reader has no way to recover the error. It is also not confirmable from a served text, so without a rule every such name would sit PROVISIONAL forever. The rule converts an unresolvable per-name question into a resolvable per-language one.
Stated beside it purely for contrast: ch in the same orthographies is /tʃ/ — Chilala → شيلالا — which matches English habit and causes no trouble. Recorded so nobody generalises the lesson into “trust the English reading”.
