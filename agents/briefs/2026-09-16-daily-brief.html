Research · ruling #54, a 404 is not a death certificate
A status code is a fact about a URL. A citation is a promise about a document. When a cited URL stops serving, the question is not is this source dead? but where does this document live now? — and the publisher is searched before anything is superseded or carried or dropped.

It needed a number because it is the missing branch of an existing rule. Supersede don’t resurrect handles the case where the world moved on and the old claim is now wrong. It has no language for the case where the world did not move at all and only the address did — and those two demand opposite actions. Also named, so a sweep never reports them as one thing again: three unreachabilities, not one. A 404 is a server denying a path, and is the strongest evidence you have that the publisher is alive. A 403 is a server denying us. A refused connection is nothing answering at all, and carries no information about the document whatsoever.
Deliberately not done: teaching the link checker to hunt for replacements. A tool that searched would start proposing, and a proposed citation is a figure composed from a pattern. The judgement stays with a person reading the tool’s output.
