Research-to-learn · ruling #16 — verify the thing itself
The outage pays its toll forward as the week's durable rule: a passing local build is not a passing deploy. Binding forms: when dependencies change, the gate runs npm ci from the committed lockfile (npm install tolerates — and silently repairs — the exact desync that kills npm ci); lockfiles are never hand-edited, only regenerated; live deploys are verified by a marker only the new deploy can serve, never an HTTP 200 or an ambiguous count. Filed as the third instance of a now-named meta-pattern — sitemap (06-07), dek-count (07-04), lockfile (07-06): verify the artifact in the environment that judges it, not through a proxy that is easier to reach.
