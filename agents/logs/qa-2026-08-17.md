## 4. Orphan sweep — NEW, and it failed on its first run

The chrome sweep checks links pointing outward. It cannot see a page that nothing points to. Asking the converse produced today's defect.

**`/madar/valence/`** — *VALENCE — The Elements of Good Education*, 540 KB, shipped 2026-08-08, revised 2026-08-10:

| Check | Before | After |
|---|---|---|
| Inbound links from anywhere on the site (all 82 pages grepped) | **0** | 0 — *nav placement deliberately deferred, see below* |
| Sitemap entry | **absent** | present |
| `rel="canonical"` | absent | present |
| Open Graph / Twitter card | absent | full set present |
| `meta robots` | absent | `index, follow` |
| Feed autodiscovery | absent | present |
| Outbound links back into Madār | **0** | 3 (Read Madār · Editions · النسخة العربية) |
| **Served pages vs sitemap URLs** | **82 vs 81** | **82 vs 82** |

**Cause.** VALENCE is served from `web/public/` as a static file. `@astrojs/sitemap` enumerates the Astro route graph, which `public/` files never enter, so it was omitted silently. `robots.txt` points crawlers at the sitemap; the sitemap did not list the page; nothing linked it. **For nine days the only route to it was being told the URL.**

**The tell was already in this log's own numbers** — 82 pages against 81 sitemap URLs, a difference of exactly one, present since 08-08 and never compared. That comparison is now a standing check.

**Fixed this run:** `customPages` in `astro.config.mjs` (with the general rule written into the comment), plus the head tags and the return route on the page itself. Re-verified in build `0817b`: 82 pages, **82 sitemap URLs**, feeds still 38/38, chrome sweep still zero unresolved.

**Deliberately not fixed — editorial, not QA** (handed to the Designer and the founder in `agents/growth/2026-08-17-orphan-page-audit-valence.md`): chrome placement, an `og:image`, and whether VALENCE gets an Arabic entry point. Adding a nav item unilaterally would be the mirror of yesterday's defect — a promise made in the chrome that nobody decided to make.

**Rule codified in the RUNBOOK today.** Third member of one family: flag-sweep inversion (08-09), chrome 404 (08-16), orphan page (08-17). *A green check is scoped to what it enumerates.*
