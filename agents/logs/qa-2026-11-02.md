From **2026-10-08 to today** the tool's header read *DECLARATIONS — markup that names a URL without
fetching it, NOT asserted*, on this stated ground:

**The format half is true. The origin half was false on the day it was written.** `qa_consumer_surface`
asserts that an `og:image` is a raster carrying alt text. It contains **no origin comparison at all** —
verified by reading the whole file for a netloc parse, a host set or a literal origin: three hits, all
three in prose comments, zero in code. No other gate covers the class either. So the one instrument whose
whole subject is *the publication's privacy posture* handed 1,203 declarations to a sibling that had never
taken the question, and **nothing re-read the sentence for 25 days.**

This is the harder shape than kind E, and worth saying why: **a delegate looks like coverage.** A decline
that says *nothing checks this* invites somebody to check it; a decline that says *the instrument next
door checks this* closes the question for every reader who does not go and look.

**Measured before anything was asserted (#93):** 1,203 declarations across 135 served pages — 665 `link
rel=alternate`, 134 `canonical`, 135 `og:image`, 135 `twitter:image`, the rest `og:url` and relative — and
**0 naming an origin we do not own.** So the floor sits exactly at today's reality rather than above it,
which is the condition that makes the assertion free.

**Limb 2 shipped**, inside the tool that already parsed and classified these URLs and merely never asserted
them. The asserted classes are split by what a foreign origin would actually do:

* `canonical`, `alternate`, `og:url` — these name **us**. A foreign origin here fetches nothing; it tells a
  crawler somebody else is the canonical home of our page, which is **worse than a fetch**.
* `og:image`, `og:image:secure_url`, `twitter:image`, `og:audio`, `og:video` — fetched by a scraper we hand
  the page to. The reader's browser does not fetch it; a machine acting on the reader's behalf does, which
  is the same hand-off one actor further out.
* **EXEMPT by rel, counted and printed, never asserted:** `author`, `license`, `me`. A licence link is
