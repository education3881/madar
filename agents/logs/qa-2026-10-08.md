## 2. THE HEAD — self-hosted fonts, and what the specification never contained

The 09-18 audit filed this with a defined shape: *"subset woff2 files under `web/public/fonts/`,
`@font-face` with `font-display: swap`, the `preconnect` and stylesheet `<link>` removed from
`Base.astro`, and — per #35 — proved both ways."* Every clause correct. **The scope was not in
it, for the third consecutive closure.**

Google's css2 response is **73 `@font-face` blocks over 34 distinct woff2 files**, carved by
`unicode-range` so a Latin page never fetches the Arabic cut. Five hand-written `@font-face` rules
— the obvious reading, and what every vendor's documentation shows — would have shipped **the whole
Arabic face to every English reader**: a performance regression wearing a privacy fix as a costume.
So the bundle is a **mirror**, generated by `agents/tools/build_font_bundle.py` from the exact URL
the layout carried, with identical families, styles, weights, ranges and `font-display`.

Three decisions the measurement made rather than the design:

- **`url()` is relative**, so the bundle resolves under any base and the base string keeps its
  single home in `withBase`. A hardcoded `/madar/` in a CSS file is a second home nothing checks.
- **Subset labels come from the comment immediately *before* each block.** The first draft carried
  the label forward across the scan and produced `amiri-italic-400-latin-ext` holding U+0000-00FF,
  which is latin. Cosmetic in effect, false in fact; **a filename is a claim**. Now also asserted:
  no URL may appear under two unicode-ranges, no two files may resolve to one name.
- **Licences ship verbatim.** All five families are OFL-1.1, whose §2 requires the notice to travel
  with the font. Each upstream notice is copied from the repository the files came from, not
  paraphrased. **Deliberately NOT added to sitemap `customPages`** — same disposition the served
  manifest got on 10-06, because 08-17's orphan rule is about *pages a reader should find*, not
  about every byte under `public/`. The stylesheet is their inbound path.
