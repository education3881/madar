## 4. The forward question

**Every instrument this operation owns runs in a context that can end without warning, and not one of them
knows that.**

Today's run opened by diagnosing a predecessor that died mid-sentence, and #122 put the envelope *reading*
onto the commit discipline. That fixes the measurement and leaves the deeper shape untouched: **every
gate, every emit and every probe here assumes it will finish.** `qa_claim_registers --emit` is the one
instrument that has faced this — it carries a request budget and tops its register up across runs. The
others have not been asked. Interrupted at an arbitrary point, which of them leaves a file a later run
reads as *complete* rather than as *truncated*? The `agents/stats/*.json` registers are whole-file
rewrites; `run-envelope.jsonl` and `history.jsonl` are appends; and the register emits are read back by
their own `--check` halves **as coverage**, which is the dangerous combination — **a partially written
register is indistinguishable from a register about a smaller corpus.** That is #57's defect produced by a
clock rather than by a mistake. First cut: ask which of these writes is atomic, and note that 10-30 is a
real instance to look at rather than a hypothetical, because a run did die with work in flight.
