## A fifth refusal that was not a refusal — and it is the day's most uncomfortable number

**`qa_font_payload` limb 2 went red once and clean twice on a byte-identical tree.** The final build before
the last commit reported *1 fetched font file nothing on the page justifies*; the tool run standalone on the
same `dist` was CLEAN; the build re-run twice more was CLEAN. Nothing was touched in between.

**The bytes are right. The instrument is not deterministic**, and that is worse than a hard failure. The
suspected mechanism is in the harness rather than the logic: fetches are attributed per page by clearing
one shared list before each page's load, so a request still in flight from the previous page can land after
the clear and be charged to the next page, where nothing justifies it. That shape can only produce a false
RED — it cannot hide a real dead fetch — which is exactly why it is corrosive: **a gate that sometimes reds
correct work teaches the next run to re-run it rather than to read it.** That is 2026-09-13's *a hand-run
assertion is a habit, not a gate* arriving by a different road. An assertion nobody trusts does not get
unwired; it gets re-run until it passes, and the next real red is re-run too.

Raised as **item 68**. It also exposes a property no assertion here has ever been asked for: **run the gate
N times on one unchanged tree and assert N identical verdicts.** Forty-one assertions, and determinism is
tested in none of them. That belongs with item 67 — both are about numbers and claims inside the
instruments rather than inside the publication.
