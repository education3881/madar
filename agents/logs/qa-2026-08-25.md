## 1. Defects found this run

### P0 — the `lastmod` resolver would have broken the deploy on its first push (never shipped)

Yesterday's `web/src/lib/sitemapLastmod.mjs` uses the pathspec `web/src`. **A
git pathspec resolves relative to the current directory**, and the workflow sets
`working-directory: web`, where `web/src` matches nothing, git exits 0, and the
file/date map comes back empty — tripping the resolver's own
"EMPTY file/date map" guard and failing the build.

**The guard written to prevent a silent CI failure would have caused a loud
one.** Ruling #16 biting the very file whose docblock cites #16.

**Fix:** `:/web/src` and `:/web/public` — git's repo-root-relative pathspec
magic, which resolves identically from any cwd and is the only form under which
the emitted repo-relative paths match the keys we look up.

**Verified in the judging environment:** built with `CI=true` inside a real,
non-shallow clone. **82 URLs, 82 `<lastmod>`.** 81 share the 08-23 chrome date
and VALENCE carries its own — correct, since `max(content, chrome)` is the
documented design and the chrome genuinely last changed on 08-23.

### P1 — the same resolver made the site unbuildable outside a git work tree (never shipped)

Shallow repo and no-repo-at-all shared one fatal path. **Wrong data and missing
data are different failures.** Shallow stays always-fatal (silently wrong
output); no-repo is now fatal **in CI only**, and a loud warning elsewhere, so
the tree builds from a copy. Filed into ruling #35.

### P1 — 471 chrome strings served under a language they are not written in (LIVE, 92 days)

Third surface of the consumer question, first one aimed at a **human** rather
than a machine. A screen reader takes its voice from the nearest `lang` and
never from the script of the characters, so Arabic under `lang="en"` is not
accented English — it is noise.

Breakdown and fixes: see `agents/guidebook/2026-08-25-an-assertion-must-be-proved-against-a-control.md`.
Headline: 81 `العربية` + 79 `English` (language switchers — `hreflang` describes
the *destination*, not the link text), 79 `Madār` (the Latin half of a wordmark
whose Arabic half has been marked since launch), **40 × `Skip to content`
untranslated on every Arabic page**, 40 `RSS`, 114 across `WhatsApp`/`X`/`Email`
(**every `aria-label` on that component was localised; the three visible
captions were not**), 38 still colophons (split into script runs via the new
`web/src/lib/scriptRuns.ts`).

**471 → 0** across the same 3,230 checked nodes.
